# Transcriber

Личный инструмент: видео с YouTube или RuTube → текст → разбор через Claude. Всё это
работает из боковой панели Chrome, а каждый запуск записывается в SQLite.

## Зачем

Видео часто остаются фоном: включил и слушаешь вполуха. Transcriber
предлагает сначала прочитать текст: получить расшифровку, задать по ней
вопросы (о чём ролик, верны ли факты, какие куски стоит посмотреть) и уже
потом решить, тратить ли на видео время.

Лог в базе нужен, чтобы проверить, работает ли это на самом деле: открывался
ли разбор, посмотрено ли видео после него или пропущено. Эти данные потом
сравниваются с историей просмотров YouTube (Google Takeout).

## Как устроено

```
Chrome side panel (extension/)
        │  native messaging
        ▼
host.py ── ставит задачи в очередь ──► worker.py
                                         ├─ transcribe.py  субтитры или whisper.cpp
                                         └─ analyze.py     claude -p с промптом
store.py / schema.sql — SQLite: видео, запуски, разборы, настройки
```

**Расшифровка.** Сначала берутся субтитры YouTube (около 2 секунд). Их
качество проверяется по трём метрикам: доходят ли до конца ролика, какую долю
времени покрывают, сколько слов в минуту. Предпочтение отдаётся ручным
субтитрам, потом автоматическим; переведённые не используются. Если субтитры
не подходят, аудио скачивается через yt-dlp и распознаётся локально в
whisper.cpp (CPU, BLAS). Сегменты с низкой уверенностью помечаются `~`, чтобы
разбор не опирался на расслышанное неверно.

**Разбор.** В настройках **Analysis → Analyze with** можно выбрать Claude
или ChatGPT. Расшифровка и промпт из `prompts/` передаются в Claude Code
(`claude -p`) или Codex (`codex exec`) по подписке, без API-ключа. Веб-поиск разрешён, он нужен для
фактчекинга. Доступ к файлам и shell отключён. Уточняющие вопросы продолжают
ту же сессию (`--resume`), поэтому повторно отправляется только сам вопрос.
Каждая ветка сохраняет своего провайдера: смена настройки применяется к новым
разборам, а уточнения продолжают исходную ветку. Для ChatGPT нужен Codex CLI
или расширение Codex в VS Code с выполненным входом в ChatGPT (`codex login`).
По умолчанию выбран Claude. После изменения кода перезагрузите расширение и
откройте панель заново; уже запущенному воркеру дайте завершить работу и выйти.

**Панель.** Расширение MV3 с двумя вкладками. «Transcribe»: расшифровать
открытое видео или ссылку, список роликов, статус воркера. «Analyse»:
выбрать промпт или задать свой вопрос, прочитать ответ, задать уточняющие
вопросы и отметить итог: посмотрел, частично или пропустил. Разбор занимает
несколько минут, поэтому он идёт в фоне и по готовности приходит уведомление.

## GPU для расшифровки

В **Settings → Transcription → Use GPU (Vulkan)** можно переключить Whisper
между CPU и видеокартой. Настройка сохраняется и применяется к следующей
расшифровке, в том числе сохранённых и импортированных записей. Уже запущенная
задача продолжает работать в прежнем режиме. Субтитры по-прежнему используются
первыми. По умолчанию GPU выключен; CPU threads нужны и при работе с GPU.

Для AMD Radeon на Windows используется Vulkan. Однократная установка:

1. Установите Visual Studio Build Tools с компонентами **Desktop development
   with C++** и **C++ CMake tools for Windows**, а также Vulkan SDK
   (`winget install --id KhronosGroup.VulkanSDK --exact --source winget`).
2. Из папки проекта запустите
   `powershell -ExecutionPolicy Bypass -File host\build-whisper-vulkan.ps1`.
   Скрипт скачивает официальные исходники whisper.cpp v1.9.5 и собирает
   отдельный исполняемый файл в `whisper/vulkan/`. Исходная CPU-сборка остаётся
   в `whisper/`; модели общие. На другом компьютере можно повторить сборку
   или скопировать всю папку `whisper/vulkan/` на совместимый Windows x64.
3. Перезагрузите расширение в `chrome://extensions`, откройте панель заново
   и включите **Use GPU (Vulkan)**. Если воркер уже запущен со старым кодом,
   дождитесь завершения задач и его выхода (около минуты без работы).

Нужен драйвер видеокарты с поддержкой Vulkan. Если GPU не удалось включить,
задача покажет ошибку; переключите настройку обратно на CPU для повторного
запуска. Переключатель относится к панели и общему CLI `run.py`;
самостоятельный `transcribe_file.py` использует собственные параметры.

## Прогресс и оценка времени

Полоса расшифровки показывает процент аудио, обработанный Whisper. Загрузка
модели, поиск речи, подготовка аудио и сохранение показываются отдельными
этапами; во время ожидания новых данных процент сам по себе не растёт.
Короткие задачи показывают оставшееся время в секундах и приблизительный
диапазон, который уточняется по скорости текущего запуска.

История скорости разделена по CPU/GPU, модели, сборке Whisper, потокам,
языку и настройкам VAD/декодирования. Для нового профиля сначала используется
грубая оценка с широким диапазоном; после нескольких запусков она обучается
на их времени загрузки и обработки. Старые записи без этих данных в обучение
Whisper не попадают. Сетевое скачивание и локальная конвертация оцениваются
отдельно. Для YouTube оценка очереди предполагает, что потребуется аудио;
при наличии подходящих субтитров работа может закончиться намного быстрее.

Проверка точности на накопленной истории: `python estimates.py` выводит
медианную ошибку в секундах и долю попаданий в диапазон для Whisper. Каждая
проверяемая запись предсказывается только по предшествующим запускам того же
профиля; для отчёта нужно не меньше четырёх подходящих записей.

## Запись звука с любого сайта

В панели нажмите **Choose what to record**. Выберите отдельный плеер или
**Whole tab**, затем нажмите кнопку записи. Записывается звук, который
воспроизводится с этого момента; для записи ролика целиком сначала перемотайте
его к началу. **Stop & save** сохраняет только звук — Whisper автоматически
не запускается. Запись остаётся в списке с пометкой **Audio saved · not
transcribed**. Нажмите **Transcribe** у записи, когда захотите получить текст.
Затем текст можно разобрать выбранным провайдером во вкладке Analyse.

**Whole tab** записывает весь звук вкладки одной записью, в том числе из
нескольких плееров. Можно закрыть панель, переключить плеер или перейти на
другую страницу в той же вкладке. Паузы и тишина запись не останавливают.
Запись заканчивается по Stop / Discard, при закрытии вкладки или прекращении
захвата браузером. Другие вкладки и микрофон не записываются.

Нужен Chrome 116 или новее. После обновления расширения перезагрузите его в
`chrome://extensions` и разрешите новые права захвата вкладки. Для начала
записи нажмите значок Transcriber на нужной вкладке и откройте панель.
Если отдельный плеер даёт тишину или отказывает в захвате, попробуйте Whole tab.

### Перенести запись на другой компьютер

1. Сохраните запись через **Stop & save** и нажмите **Download audio** у её
   строки в списке. Скачается обычный `.webm` со звуком, без перекодирования.
   Кнопка доступна и после расшифровки, пока исходное аудио не удалено.
2. Передайте файл на другой компьютер любым удобным способом.
3. В Transcriber на другом компьютере нажмите **Import audio or video**
   и выберите файл. Импорт сохраняет аудио, но не запускает Whisper.
4. Нажмите **Transcribe** у импортированной записи. Расшифровка и дальнейший
   разбор работают так же, как для записи, сделанной на этом компьютере.

Импорт принимает аудио- и видеофайлы, которые может прочитать установленный
ffmpeg: MP3, MP4, OGG, WAV, FLAC, M4A, AAC, Opus, WebM и другие.
Из видео берётся первая звуковая дорожка; файл без звука не импортируется.
Название берётся из имени файла. Аудио сохраняется в WebM: существующие
аудиозаписи WebM переносятся без изменений, Opus/Vorbis из других контейнеров
перепаковываются без перекодирования, остальные кодеки конвертируются в Opus
128 кбит/с. При скачивании импортированной записи вы получите этот WebM.
Для длинных файлов подготовка аудио может занять несколько минут.
История разборов и ссылка на исходную страницу с аудиофайлом не переносятся.
На принимающем компьютере должны быть установлены обычные зависимости
Transcriber, включая ffmpeg/ffprobe и Whisper с моделью. Перенос файла сам
по себе не включает GPU. Без расширения можно воспользоваться существующим
CLI: `python transcribe_file.py "запись.webm"` — он создаст текстовый файл.

## Файлы

| Файл | Что делает |
|---|---|
| `transcribe.py` | URL → расшифровка (субтитры / whisper.cpp) |
| `analyze.py` | запуск Claude Code с промптом, уточняющие вопросы |
| `run.py` | CLI: расшифровать, сохранить, по желанию разобрать |
| `channel.py` | список видео канала (YouTube, RuTube) |
| `batch.py` | несколько расшифровок в очереди, оценка времени |
| `export.py` | расшифровки в .txt или zip с заголовком |
| `store.py`, `schema.sql` | SQLite и миграции |
| `settings.py` | настройки в базе, константы в модулях служат значениями по умолчанию |
| `jobs.py`, `worker.py` | очередь задач и фоновый воркер |
| `estimates.py` | общий прогноз времени, живая оценка и проверка точности на истории |
| `host.py`, `host/` | native messaging host для Chrome и его установка |
| `extension/` | боковая панель |
| `prompts/*.md` | промпты для разбора: summary, factcheck, worth-watching |
| `data_analysis.ipynb` | анализ собранных данных |

## Установка на новый компьютер (Windows)

Всё, кроме самой панели, работает локально, поэтому каждому компьютеру
нужна своя копия проекта целиком. Понадобятся две вещи:

- **код**: `git clone https://github.com/itisiainis/Transcriber.git` или ZIP
  репозитория, распакованный в любую папку;
- **архив с whisper и моделями** (`models.zip`, около 1 ГБ). В git его нет,
  его передают отдельно. Внутри папки `whisper\` и `models\`.

Дальше:

1. Положите `models.zip` рядом с `setup.bat` (или на рабочий стол, или в
   «Загрузки»: установщик сам его найдёт).
2. Дважды щёлкните **`setup.bat`**. Установщик:
   - найдёт Python 3.10+ (или предложит поставить через winget), создаст
     `.venv` и поставит пакеты;
   - проверит ffmpeg (или предложит поставить);
   - распакует whisper и модели и проверит, что whisper запускается на этом
     компьютере (если не хватает Visual C++ runtime, предложит поставить);
   - подберёт число потоков под процессор и модель из тех, что есть;
   - зарегистрирует host для Chrome.

   Запускать его повторно безопасно: сделанные шаги он пропускает.
3. В Chrome: `chrome://extensions` → «Режим разработчика» → «Загрузить
   распакованное» → папка `extension\`. Закрепите иконку Transcriber и
   нажмите её: откроется боковая панель. Внизу должно быть «Worker online».

Для разборов нужен один из двух вариантов, на своём аккаунте:
**Claude Code** (`claude`, вход по подписке Claude) или **Codex** (CLI или
расширение Codex в VS Code, вход по аккаунту ChatGPT: `codex login`).
Установщик найдёт, что есть. Если есть только Codex, он сразу выберет
ChatGPT; переключить можно в настройках панели. Расшифровка работает и без
них.

Если в архиве есть GPU-сборка (`whisper\vulkan\`) и установщик написал,
что видит Vulkan-устройство, включите «Use GPU» в настройках панели.

**Если что-то не так:**
- «Host not connected»: запустите `setup.bat` ещё раз. Если папку проекта
  переносили, нужно перерегистрировать host с новым путём.
- ffmpeg только что поставлен: полностью закройте Chrome и откройте снова,
  иначе панель его не увидит.

У каждого компьютера свои база (`transcriber.db`), расшифровки и разборы:
они не синхронизируются и в репозиторий не попадают.

## Команды

```
python run.py <url> [--prompt factcheck | --ask "вопрос"]
python analyze.py last --more "уточняющий вопрос"
python settings.py                      # текущие настройки
python channel.py <ссылка на канал>     # список видео канала
python batch.py add <видео или канал>... [--limit N]
python batch.py list | run | clear      # очередь: оценка времени, запуск, очистка
python export.py --last 3               # расшифровки в .txt (--mode separate → zip)
```
