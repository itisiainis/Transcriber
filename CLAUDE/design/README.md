# Screens

Mockups of the Chrome side panel. The canvas they came from is a private
Claude artifact — Claude Code cannot fetch it, so these files are the copy
that matters.

**These are for proportion and feel.** The rules that actually govern the
build — what each colour means, where the prompt choice happens and why, what
must never come back — are written out in `../CLAUDE.md` under "The UI".
Where a screenshot and that text disagree, the text wins.

## Capturing these

From the canvas, in focused mode on each artboard, screenshot the panel
area only (not the surrounding canvas), and save with the names above.
A screenshot including the canvas background wastes most of the image on
grey and makes the panel too small to read.
